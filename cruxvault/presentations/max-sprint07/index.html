Setup · how to read every result

One metric, one benchmark, one yardstick

Metric · r_spec
The correlation between prediction and truth after the signal shared by all cell types is removed. It scores the part of the signal that imputation exists for.
  • Benchmark A v3: 45 held-out ENCODE biosamples, 283 target tracks, 6 chromosomes. Intervals are 95% bootstrap intervals over the held-out biosamples.
  • Seed gap (the difference between two runs that differ only in the random seed): 0.001 to 0.011 r_spec over five recipes, 0.007 on average. A single-run difference under about 0.01 is not a finding.
  • Seven threads: recipe, noise floor, cell-state vector, processing artifacts, variant effects, compute, literature.
Result 1 · the reference recipe

RNA input plus an equal-weight loss raises r_spec by a tenth

  • R2 vs R1: r_spec 0.273 → 0.304 (two seeds each), about 4.5× the 0.007 seed gap. R1 is last sprint's best model: frozen DNA-sequence features plus attention over 32 similar reference biosamples.
  • The loss matters most. The old loss is a Gaussian negative log-likelihood (NLL), which down-weights bins with high predicted variance. The new loss weights every 25 bp bin equally.
  • RNA helps once the loss counts the peaks. The interaction is +0.012 [+0.005, +0.019].
  • By mark: the largest gain is on H3K79me2 (+0.150). H3K27ac gains +0.024. H3K9me3 and accessibility show no gain.
Result 2 · the noise floor

The noise floor is 0.28, not 0.38, so there is more room than we thought

  • Noise floor: the share of a track's variance that is sequencing noise. No model can go below it.
  • Cause: sprint 06 read depth from the ENCODE manifest, which lists one replicate. The benchmark tracks pool both replicates, so the floors were set at about half the true depth.
  • Our pseudoreplicate floors hold at the pooled depth for reads ≥ 60 bp (within 0.002). For 36 bp reads they overstate the noise by about 0.1.
  • On six experiments with both kinds of data, biological replicates sit only 5% above the pseudoreplicate prediction. Over all 282 targets the floor is 0.28.
Result 3 · where the error is

R2 recovers about a quarter of the cell-type-specific signal that can be recovered

  • Normalized error (MSE ÷ track variance) for R2 is 0.665. It splits into 0.110 calibration, 0.027 shared signal and 0.527 cell-type-specific signal.
  • Of the 0.527 specific error, 0.282 is noise (the corrected floor) and 0.245 is predictable but not yet explained.
  • Recovered share: training-track average 0.07, R1 0.21, R2 0.25 (seed 1).
Result 4 · cell state through TF expression · negative

A transcription-factor expression vector gives no cell-state information; its training-time gain is regularization

  • The test: Corgi+-style FiLM layers (they scale and shift internal features from a vector) feed the expression vector into CANDII.
  • Swapping in another biosample's vector at prediction time changes r_spec by +0.001 [−0.002, +0.003].
  • Constant and shuffled vectors reproduce or beat the training gain, so the gain is noise injection.
  • Why: the RNA coverage track already carries each TF's expression where it matters. Cell state now moves to the reference panel.
Result 5 · processing artifacts · on Mehdi's testbed

Read-level artifacts can be corrected; peak-caller artifacts cannot yet

Correctable · which reads are counted
Depth, single- vs paired-end, read length, duplicates, mapping quality. For histone marks, a per-bin lookup curve comes within 0.05 of a no-change resample (most settings within 0.02). Depth is exact in counts. The curves transfer to a new mark.
Not yet · how MACS2 makes p-values
Fragment extension, the control experiment, the control scaling. The reads are identical, but a per-bin curve leaves 3% to 41% of the variance unexplained. These settings are invisible in counts.
  • On your transfer failure (for example, 15M → 3.75M): Max's untested hypothesis is that the network saw absolute depths, not ratios, and never saw a pair without the base.
  • On counts-only CANDI: correct for depth. But the largest artifacts left in p-values come from the peak caller. A counts-only model must also predict the background rate λ to fix them. DNase needs its own corrections.
Result 6 · variant effects on histone QTLs

The reference panel blocks variant effects; a learned cell-state vector nearly matches Borzoi

  • Task: predict the measured allele effect at histone QTLs (variants whose alleles carry different amounts of a mark) in 75 lymphoblastoid lines.
  • The panel model copies reference tracks, which do not change with the allele. Reference dropout restores the direction of the effect, not its size.
  • Dropout costs imputation 0.007 [0.001, 0.013] r_spec, within the pre-registered 0.02.
  • Caveat: the frozen sequence encoder was trained on GM12878's own marks. A clean test needs an assay it never saw.
Result 7 · compute

A seventh of an H100 trains the recipe in 10.4 hours and matches CPU

  • GPU slice (1g.10gb) vs CPU, same recipe: −0.005 [−0.011, +0.000] r_spec in fp32. That is inside the seed gap. The run costs one and a half H100-hours.
  • bf16 vs fp32 on GPU: −0.002 [−0.007, +0.003].
  • A bigger batch does not shorten training: batch 32 × 60k steps loses 0.010 [0.003, 0.018] to batch 8 × 240k steps.
  • Spend: about $335 of the $2,000 budget at list price.
What it asks of us

Three questions for Mehdi, and the one gap left in goal G1

  • Rival comparison (the one thing G1 still lacks): which is cheaper? Port the rival methods to Benchmark A v3's held-out set, or port its 45 biosamples and 283 targets to our evaluation regime. Every table should also report the training average and a retrieval baseline.
  • Testbed question 1: does paired-end duplicate marking keep a pair when either mate is unique?
  • Testbed question 2: do the single-end base and the paired-end arm come from the same library?
  • Max's next steps: a single-head run with the two-head loss balance; a random-vector regularizer; the reference panel as the place cell state enters; read-level correction inside training; a clean held-out-assay variant test.
