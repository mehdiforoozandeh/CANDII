Literature · what a processing choice can move

A pipeline choice can move two different signals, differently

  • Raw counts answer "how many reads piled up," fixed the moment reads are filtered.
  • The −log10 p-value answers "how surprising," and depends on the control, so a knob that never touches a treatment read can still move it.
  • Because the two move independently, the survey behind this deck scored every knob on both axes, never as one number.
Literature · why these ten knobs

The survey found measured evidence for exactly these choices

  • Six knobs change which reads enter the pile-up itself: depth, run type, duplicates, read length, mapping quality, and antibody efficiency.
  • Four more knobs leave treatment reads untouched and move only the p-value: control scaling, control identity, control depth, and fragment extension.
  • The aligner and the blacklist mask move peak calls by less than replicate noise, so the survey left them out.
The knobs · which reads enter the pile-up (q2)

Depth thins the pile-up itself, and the p-value moves with it

  • Each level thins the same base BAM by a fixed fraction: 15M, 7.5M, 3.75M reads.
  • The caller's Poisson test runs on raw counts, not a depth-normalised scale, so both panels shrink together.
The knobs · which reads enter the pile-up (q2)

Paired-end reads measure the fragment; single-end reads guess it

  • Single-end reads sequence one end and estimate the rest of the fragment by cross-correlation.
  • Paired-end reads sequence both ends, so the fragment length is measured, not guessed.
  • The pipeline's dedup rule and the shape it hands the caller change site by site, so a quantile-matching fix cannot fully undo it.
The knobs · which reads enter the pile-up (q2)

Shorter reads and a looser MAPQ filter both change which reads reach the pile-up

  • Read length: cropping the 101 bp reads to 50 or 36 bp removes the bases that resolve a repeat, so fewer reads map uniquely.
  • MAPQ filter: lowering the threshold from 30 to 10 or 0 admits multi-mapping reads, mostly inside repeats.
The knobs · which reads enter the pile-up (q2)

Duplicates and antibody efficiency both dilute the true signal

  • Duplicate removal: no_dup_removal = true keeps every PCR duplicate, which concentrates inside real peaks, not outside them.
  • Antibody proxy: replacing a fraction of treatment reads with control reads mimics a failing antibody and collapses the peak toward background.
The knobs · how the control & caller are set (q3)

Rescaling or swapping the control moves only the p-value

  • Control scaling: --ratio at k × the default multiplies the control before the Poisson test, while the treatment bar never changes height.
  • Control identity: swapping in another cell line's control, or none at all, changes what "surprising" means for the same treatment reads.
The knobs · how the control & caller are set (q3)

A thinner control or a wider fragment — again, counts untouched

  • Control depth: subsampling only the control to a fraction q of its reads adds Poisson noise to the background estimate, while the treatment BAM stays untouched.
  • Fragment extension: --extsize at k × the fraglen widens or narrows the smoothed pile-up the caller scores, while raw counts still come from unextended read starts.

The 130 counterfactuals · build state

126 of 130 products are built; 4 are in flight

  • Seven tracks run through two ENCODE pipelines: chip-seq-pipeline2 for the six histone marks, atac-seq-pipeline in DNase mode for the seventh.
  • DNase-seq has no control, so the four control-side knobs do not apply to it.
  • Every product is the same five files, at 25 bp bins on GRCh38: counts, control counts, p-value, covariates, and provenance.
