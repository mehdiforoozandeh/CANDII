This deck follows the transformation grid (t118) and the depth-offset deck (t125). It asks one question: if g is built so that any pair of settings composes through one shared middle, does the model then work on pairs it never trained on?

Every number on the slides and in these notes is read from the result files when the deck is built. Nothing here is a verdict.

Motivationtwo words first

The model trains only on base ↔ arm pairs; arm → arm pairs are never seen in training

Panel (a): each track was rebuilt many times, changing one setting (a knob) at a time; each rebuild is an arm. Training uses only pairs between the base track and one arm, in both directions (solid). A pair between two arms (dashed) is never trained: the model must work it out from the settings alone.

Panel (b): the depth law. With fewer reads, every bin scales by the read ratio. We read the predicted total over the source total, on a log2 scale, against the true ratio. The error is the gap between the two; 0 is perfect.

Motivationthe problem, from the earlier grid

Every earlier design fits the pairs it trained on, and misses the pairs it never saw

Panel (a): each column is one design of the earlier grid (A to D; a 2 means g also reads the bin's level). Each design has two versions of g: a circle is one g per track, a square is one g across tracks. Dark is the error on trained depth pairs; pink is on never-trained depth → depth pairs.

Panel (b): how much better the real model is than its no-covariates twin (the same model that sees random settings), per knob, as a share of the twin's CRPS. Higher is better. Every knob loses gain on its never-trained pairs, but MAPQ and control fraction gain little even when trained.

The four control and caller knobs do not change the counts at all, so they are left out of panel (b).

Motivationdiagnosis · four suspects

We checked four suspects for the gap: one is ruled out, one is indirect, one mostly holds, one is open

ruled out
1 · The check itself
We recomputed the depth law from the raw count histograms, and summed the counts of every depth track.
indirect
2 · The +1 in log(1 + count)
On log(1 + count), the depth law is a curve, not a straight line, because of the +1. Old A compensates with a steeper line.

Going arm → base → arm with two trained maps beats the direct arm → arm map that g never trained on.

The negative binomial likelihood gives high-count bins less weight, so it does not force the predicted total to match the target's. Not tested yet.

Card 1: if the check were wrong, the gap could be fake. A second computation, from the count histograms, gives the same numbers, and the depth tracks hold the counts their read depth says. So the check stands.

Card 2, panel (a): on log(1 + count), the exact depth law is a curve, not a line, because the zero bins stay at zero. The best straight line has a slope above 1 and an offset below ln r (r is the read ratio). That is what old A learned. It is indirect: it explains how A fits, not why never-trained pairs fail.

Card 3, panel (b): composing two trained maps through the base is far closer to the law than the direct map. So the maps g learned are fine where it trained; it is g's guess for a new pair of settings that is off.

Card 4: a Poisson likelihood for the mean would force the predicted total to equal the target total for every pair; the negative binomial likelihood we use does not. The loss is still a suspect; no check has been run.

Motivationwhat to change

Real data has few arm → arm examples, so the fix must come from g's structure

Option 1 · more pairs
Train on arm → arm pairs too.
Public data rarely holds the same sample processed two ways, so CANDI cannot rely on such pairs.
Option 2 · structure (this work)
Make every pair pass through one shared middle.
Suspect 3 says routing through the base works. Build that route into g: encode the source with its own settings, decode with the target's. Then arm → arm composes by construction.

CANDI's training data comes from public experiments. Two processings of the same sample are rare there, so the model cannot learn arm → arm maps from examples.

The diagnosis points to structure: the trained maps are good, and chaining two of them works. An encoder-decoder makes that chaining part of the model.

Methodthe idea

An encoder-decoder g reads one track's settings at a time, so any two tracks compose

Lane (a), the old g: it reads the source settings c and the target settings c′ together. An arm → arm pair is a new combination of inputs, which g has never seen.

Lane (b), the encoder-decoder: one shared network φ reads one track's settings and gives that track's coordinates. The encoder removes the source's settings, giving a covariate-free latent z; the decoder adds the target's. Any pair, trained or not, uses the same two pieces. With c′ = c the model returns X itself.

Methodrung A · the exact inverse

Rung A: encoding is the exact inverse of decoding, so a round trip returns the start

φ(c) gives two numbers per track: a location α and a scale β. Encoding subtracts α and divides by β; decoding multiplies by the target's β and adds its α. The result is still one straight line on log(1 + count), as in old A, with slope b = β(c′)/β(c).

Two arms: β learned, or β fixed at 1 (then the map is a pure shift). In both, b for c → c′ times b for c′ → c is exactly 1. Keep that in mind for result (d).

The spread of the negative binomial comes from a second small network ψ that reads the target's settings only.

Methodrung D · a learned decoder

Rung D: the CNN is cut in two, an encoder tuned by the source and a decoder tuned by the target

Top: old D's four dilated layers are split 2 + 2. The first two are tuned (scaled and shifted, called FiLM) by g_enc, which reads the source settings; the last two by g_dec, which reads the target's. There is no shortcut from X to the output: everything passes through the latent Z. The view stays the same as old D.

Bottom: the loss for one trained pair (X, c) → (X′, c′). Two cross terms (the real job), two self terms (a round trip on one side), and a pull λ that asks both latents to agree. λ = 0 drops the pull.

λ is picked per version of g by the lowest validation NLL on chr22, the earlier grid's rule.

The baselines are retrained, not reused, because this run holds the middle depth out of training. Every arm has a no-covariates twin: the same model fed random settings, which can only learn one average map.

Encoder-decoder D has no shortcut from X, so it cannot start as the identity: it starts as a constant map. Old D starts at the identity. This is a known difference, named again in the doubts.

Results(a) the depth law

No encoder-decoder arm closes the never-trained depth gap; the held-out depth is easy for every arm but encoder-decoder A

Each row is one arm; each bar is the median error over that pair group, with the 25th to 75th percentile as a whisker. The small ticks are each seed's own median: a gap smaller than their spread is not a gap. Log scale.

The held-out depth sits between two trained depths, so it tests interpolation only. Encoder-decoder A misses even its trained depths; result (d) shows why.

Results(b) the other knobs

Encoder-decoder D gains more on trained pairs, but falls below its twin on never-trained pairs of three knobs

Gain over the twin: for each pair, (twin's CRPS − real CRPS) / twin's CRPS, then the median over pairs. Above 0, the settings help; below 0, the model is worse than ignoring them.

Filled dot: trained pairs. Open ring: never-trained pairs of the same knob. The line joins the two for one arm. Two-knob pairs are all never-trained, so they have a ring only.

Results(c) the fit on trained pairs

Encoder-decoder D keeps old D's fit on trained pairs; encoder-decoder A loses fit, mostly in scale error

CRPS on counts over the trained pairs, mean over a track's pairs, then over tracks, then over seeds. Lower is better. Dark is the oracle-scaled part (left after the best single rescale); light is the scale error (what that rescale removes). The whisker is the range over 3 seeds; the grey tick is the no-covariates twin.

So the encoder-decoder D structure costs nothing on trained pairs. Encoder-decoder A's loss is mostly a wrong overall scale, which result (d) explains.

Results(d) why encoder-decoder A fails

The exact inverse forces the two directions' slopes to multiply to 1, but old A needs a slope above 1 both ways

Each point is one trained or held-out base ↔ depth pair of one track and one seed. ln r is the log read ratio, target over source; less depth is on the left. The dashed lines are the depth law on log counts: slope b = 1 and offset a = ln r.

Old A sits above b = 1 on both sides: that is the +1 compensation of the diagnosis. Encoder-decoder A cannot do that: if its slope is above 1 one way, it must be below 1 the other way. It keeps the offset near 0, so a zero-count bin keeps a mean near 1, and with less depth the prediction goes up, not down.

Discussionwhat this rules in and out

Composition by construction is not enough on its own, in either form we tried

Ruled out, for rung A
An exact inverse on log(1 + count)
It cannot learn the slope above 1 that old A uses in both directions, so it misses even trained depths.
Not enough, for rung D
A learned latent, at these settings
It keeps old D's trained fit, but the never-trained depth error does not drop, and three knobs fall below the twin.
Still in play
The loss, and how the latent is trained
The negative binomial loss does not force the predicted total to match, and it is untested. Composing two trained maps through the base did work in the earlier grid.

These are readings from one exploratory run, not verdicts. Each is open to the doubts on the next slide.

Rung A: the result has a clear cause. The +1 in log(1 + count) makes the best line steeper than 1 in both directions, and an exact inverse forbids that. A fix would have to change the space (for example, a log of counts with a different offset) or drop the exact inverse.

Rung D: the structure is there and the trained fit is unchanged, yet the never-trained pairs do not improve. The doubts on the next slide could each explain this.

The loss is the one suspect not yet tested.

Discussiondoubts

Five doubts could each change the rung-D reading

The start
Encoder-decoder D starts as a constant map; old D starts at the identity. The start may shape what the latent learns.
Under-training
Interpolation only
Product identity
For knobs other than depth, each track's settings are unique per arm, so g can use them as a name. A gain or loss there may be memory, not a rule.
λ within noise

The start and the step cap together: encoder-decoder D began further from a good map and often used every step, so it may need more steps or an identity-like start before its never-trained pairs can be judged.

Product identity: within one track, every arm's settings vector is different, so for knobs other than depth g can learn "this vector means this arm". Depth has three levels in a clear order, so it is the cleanest test.

λ: the chosen λ wins by about one seed's spread, so the choice is weak.
