Does changing the training loss fix the depth law?

A head-to-head of two losses for the same small models: the full negative binomial (NB) loss, and a loss that fits the mean by Poisson. trained runs, on tracks where the right answer is known. Exploratory: readings, not verdicts.

Motivationthe problem

The model follows the depth law on pairs it trained on, and misses it on pairs it never saw

  • The depth law: halve the reads, and the predicted counts should halve. The real tracks obey it.
  • Training sees only base ↔ arm pairs. The law is tested on arm → arm pairs, such as 15 M → 7.5 M reads. These were never trained.

Source: earlier transformation grid (t118 rows 1 and 2), results/h19/depth_pairs.

Motivationwhy suspect the loss

The NB loss lets the peaks count less when it balances the totals

  • Poisson loss, with a free overall scale: at its best fit, the predicted total equals the observed total, exactly.
  • NB loss: each bin enters the balance with a weight that falls as the bin gets higher. So the totals can drift.

y = observed reads in a bin, μ = predicted mean, n = the NB dispersion (small n = more spread). The weight curve is an illustration with μ = these counts and n = 2.

Methodtwo losses

Two losses, the same model, the same output

Full NB loss (the loss we used so far)
L = − log NB( y | μ, n )
One loss trains the mean μ and the dispersion n together.
The mean is pulled by the NB balance, where high bins weigh less.
Poisson-mean loss (new)
L = − log Poisson( y | μ ) − log NB( y | μfrozen, n )
The Poisson term trains the mean. The NB term trains only the dispersion: it sees a frozen copy of μ.
The mean is pulled by the Poisson balance, where every bin weighs the same.

Both arms output an NB distribution per bin and are scored the same way. Each arm stops early on its own validation loss.

Discussionwhat it means

The loss was not the cause: the failure is in how g generalises

Reading. The Poisson-mean loss repairs the scale of a design that has the wrong form. It does not make g carry the depth law over to pairs it never trained on.
Next 1 · a composable g (already running)
An encoder–decoder g: one shared map from each side's settings to a common space, with an exact inverse. An arm → arm change then uses the same maps as the trained pairs.
Next 2 · train on arm → arm pairs
Add arm → arm pairs to training, so that the depth-law pairs are no longer unseen.

Doubts: g is shared across pairs, so the Poisson guarantee on totals holds only loosely. The two arms stop early on different losses, but most run pairs stop at the same step.
