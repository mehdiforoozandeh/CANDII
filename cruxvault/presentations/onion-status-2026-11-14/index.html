Storywhat the project asks

We split the variance of an epigenomic signal into layers, then ask how much of each layer a small model can predict

  • Variance layer (the part of the signal's variance from one source): read sampling, replicates, cell type.
  • Model ladder: six small models of equal parameter budget, from a pointwise model to a Perceiver.
  • Three goals: imputation, covariate correction (a covariate is a recorded experiment setting, such as depth), calibrated uncertainty.
  • Comparison: training-free baselines and AlphaGenome 2, on the same tracks and regions.

Panel a is the onion: the total variance of a track splits into nested layers, from read sampling at the core to cell type at the outside. Panel b is the ladder of models, each a step up in context. Panel c is the comparison: every model and baseline is scored on the same three goals.

Done(a) the data

The dataset and the evaluation set are frozen

  • Every track was built from FASTQ with the standard ENCODE pipeline of its assay. The missing tracks arrive in later dataset versions.
  • The evaluation set is the fixed list of what is scored: imputation items and pair tests on regions (explained in the next part).

Panel a shows tracks present in the frozen dataset against tracks planned, per role. Panel b shows what the evaluation set holds. The evaluation set has a hash, and every score records it, so scores on different sets cannot be mixed by mistake.

Done(b) the variance layers on real data

At bp, read sampling is the largest layer of every assay; at the broad scale the cell-type layer leads

  • Caveats. Values are on log1p counts at the depth of a pseudoreplicate half (a random half of one library's reads), so at full depth sampling is smaller. The cell-type layer also holds donor and lab, because those pairs are absent.

A layer is the difference of two pair values. The sampling layer comes from pseudoreplicate pairs, the replicate layer from isogenic replicates minus that, and the cell-type layer from pairs of other cell types minus the replicates. Each pair value has a cluster-bootstrap interval over cells; the replicate layer is small but its interval excludes zero for most histone marks. At the broad band a negative increment is drawn as zero.

This rerun replaces the first run, which had no sampling layer; no number of the first run is used.

Regions(a) what a region is

A region is one fixed stretch of the genome; of them were drawn at random from candidate blocks

  • One region = bins of bp = bp. All regions together: Mb on chromosomes.
  • The draw used only the genome mask, the chromosome sizes and seed , so every dataset version is scored on the same regions. more fit regions are kept apart.

A candidate block is an aligned block of the region size whose bins are mostly valid under the genome mask. Each tick on a chromosome is one evaluation region, drawn to scale but widened so that it is visible; grey ticks are the fit regions. Bins are the model's unit: one count per bin per track.

Regions(b) what is scored on them

Two kinds of test run on the regions: imputation items and pair tests

An imputation item hides one track of a validation cell and asks the model to predict it from the cell's other tracks. A correction pair asks the model to turn one processing view of an experiment into another view with other covariates, for example a single-end view into a paired-end view. A replicate pair compares the prediction with an independent replicate. Each pair test needs its own model forwards on every region it uses, which is why pair tests dominate the cost.

Regions(c) the and (d) the

The regions are the frozen set; the screening set runs pair tests on every th of them only

  • On the regions: the three pair-test metrics only. These are the correction gap closed against depth-only scaling, the depth-law error, and the replicate-pair gap closed per rung.
  • On all regions: the imputation items, the predicted-over-replicate variance ratio, the explained fraction per layer, the copy-leak guardrail and every signal-space metric.

Panel a lists the regions in the order the evaluation set stores them, sorted by chromosome name and then start. The screening set takes the regions at every sixteenth position of that order, starting at the first. The candidate subsets of eight and thirty-two regions are nested with it: every thirty-second region is inside, and every sixteenth region is inside the subset of every eighth. Panel b shows the same sixteen regions on the genome.

The screening set is the frozen set plus one key that names the pair regions. Its regions, items and pairs are those of the frozen set.

Regions(e) why two tiers: cost and feedback speed

  • Screening tier (pair tests on regions): fast enough to compare many arms within a day. Every number from it carries the label screening, and no selection is settled from it.
  • Settled tier (pair tests on regions): used for a settled selection until the check of the next slide chooses a smaller count. Measured today: one baseline scoring on all regions took on CPUs.

The window counts are exact: they follow from the evaluation set. The forward hours are projected from the measured forward speed of the smallest model. The store size and the metric hours are planning estimates; the first metric job will measure them. The baseline time is measured.

Regions(f) why not more regions

More regions wait for evidence; a pre-registered check decides whether pair regions are enough, and it has not run yet

  • Your ruling: the evaluation regions may go to on evidence; needs you.
  • The check, written before any data: score rung-4 runs (base and scrambled covariates, three seeds) with pair tests on all regions. A size passes if all conditions hold, e.g. each metric stays inside the % region-bootstrap interval ( draws) and the selection verdict does not change.
  • Result rule: the smallest of that passes; if none passes, pair tests stay on all regions.
  • Status: not run. Its rung-4 trainings are in the queue. Prior evidence: % of bins kept the model ordering in draws; regions are %.

The five conditions: each run's pair metrics on the subset lie inside the region-bootstrap interval of the all-region value; the same holds per assay for nearly every cell; the selection verdict of scrambled covariates against base is unchanged; the range of the correction term across seeds (maximum minus minimum) grows by at most the set factor; and the variance-ratio metric, which uses no pair test, is unchanged by construction.

The check rests on one rung and one pair of arms. You moved it from the smallest model to rung four because rung four's forwards are much cheaper; the version on the smallest model is a later phase. The study of the interval width at more evaluation regions, with a superset of regions, is also a later phase.

Iterations(a) the principle

Iterative deployment: few iterations, many parallel paths, and a paper that grows one section at a time

  • Each ship adds paper sections in paper order: Methods first, then Results, then Discussion. Each ship stands on its own.
  • A new iteration starts only for work that needs a result of the one before. Everything else starts at once, in parallel.
