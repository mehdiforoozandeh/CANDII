Motivationthe problem

One sample, three processing choices, three different tracks

Real data: H3K27ac, the same 10 kb of chr19, the same cells. Only one processing setting changes per row. All three rows share one y-axis.

Motivationwhy we care

CANDI relies on these settings, but we cannot test them inside CANDI

  • CANDI reads the settings (we call them covariates) of the input tracks and of the track it should output.
  • Inside CANDI, the covariate path and the big model are mixed. We cannot see what the covariates alone do.
Motivationthe question

We take a track X made with settings C. We ask for the same track made with settings C′. Can a model predict it from the settings alone?

We test this in isolation, on small models, on data where the true X′ exists.

Backgroundthe data

We rebuilt each track many times, changing one setting at a time

  • We reran the ENCODE pipeline from the raw reads. Each rebuild, called an arm, changes exactly one knob.
  • Reads knobs change which reads enter the pileup, so they move both outputs.
  • Control and caller knobs change only the p-value track.
  • So for every change we have the true answer X′.
Backgroundthe data

Seven tracks in three mark classes

  • 130 tracks in total: 7 base tracks and 123 arms.
  • Every result is reported per class, because the three classes have very different shapes.

DNase has no control, so it has fewer arms. Its two MAPQ arms came out identical to the base (a pipeline setting), so they are left out until they are rebuilt.

Backgroundtwo kinds of signal

Each track comes in two forms, and some knobs move only one

  • Counts: the number of reads in each 25 bp bin.
  • −log10 p: how surprising the counts are against the control. A peak caller (MACS2) makes it.
Methodthe model

A small network g reads the settings and builds the transformation f

  • We train g, not f. f is only what g outputs for one pair of settings.
  • f outputs a distribution in every bin (a mean and a spread), as CANDI does.
Methodfour designs of f

Four designs of f, from simple to flexible

A and B look at one bin at a time, so they can change magnitude only. C and D also see neighbouring bins, so they can change shape (for example, peak width).

Methodthe two rows

Row 2 lets g also read each bin's own level

  • Row 1: g reads only (C, C′). One f for the whole genome.
  • Row 2: g reads (x, C, C′), where x is the bin's own level. f can treat low bins and peaks differently.

Methodtwo versions of g

Every cell is trained two ways: one g per track, and one g for all tracks

  • One g per track: 7 small g's. Each one learns one track's arms.
  • One g across tracks: a single g that also reads the assay. It must share what it learns between marks.
Methodcontrols

Each model has twins that test one boring explanation each

The real model
Reads the true settings.
No-covariates twin
Gets random settings at every step, so it learns one average map.
If the real model wins: the settings help.
Labels-as-ids twin
Gets wrong but fixed settings, so it can memorise one map per pair.
Only pairs never seen in training can tell it apart.
Shuffled-bin twin (row 2)
g reads the level of a random bin, not of its own bin.
If row 2 wins: the bin's own level helps, not just an extra input.
Methodtraining and testing

We test on unseen chromosomes and on unseen pairs

  • Held-out chromosomes: train everywhere except chr19, 21 and 22. Pick the best step on chr22. Score on chr19 and chr21.
  • The law test: train only base ↔ arm pairs. Then score arm → arm pairs that were never trained. A model that memorised pairs has no answer for these.
Methodscoring

Lower CRPS is better, and a gain counts only if it is larger than the seed noise

  • CRPS punishes a prediction that is off, and one that is too wide. We score all bins and the top 1% of bins (the peaks).
  • Seed wobble: each model is trained with 3 random seeds. A gain counts only if it is more than 2 × the wobble.

Resultswhy A failed

One straight line in log space cannot say "no change"

  • On arms where the true counts do not change, row-1 A learned a line with slope 1.9, where "no change" needs slope 1.
  • The result: it overshoots the peaks by several times.
  • A2 picks its line per level, so the map can bend and follow the truth.
  • B, C and D already bend, so row 2 had less to fix there.

Resultsfinding 5

No design follows the depth law yet

  • The depth law: halve the reads, and the predicted counts should halve. We allow a 10% error.
  • Only one cell meets it (B2, DNase, one g per track). The others miss by 17% to 136%. We have not yet hand-checked how the law is computed.

Discussionwhat is still unclear

Four things we do not understand yet

Why row 2 explodes
The row-1 cause (one drifting spread at the lowest knot) does not explain A2, which has no knots.
Why D explodes
D has no knots and explodes in both rows. Its cause is not found.
The depth law
Every design misses it. The computation itself may be wrong, so we check it by hand first.
Shape vs magnitude
C and D can change shape, but they barely beat B. Do the settings change shape at all, at this resolution?
